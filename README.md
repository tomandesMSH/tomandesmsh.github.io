# tomandes.eu

Zdrojový kód osobního portfolia na [tomandes.eu](https://tomandes.eu/), hostováno přes GitHub Pages.

- `index.html` – hlavní stránka (CZ), `en/` – anglická verze (generuje `tools/build-en.py` z `i18n/en.json`)
- `report/` – formulář pro hlášení
- `og/` – zdroje pro social preview obrázek a favicon
